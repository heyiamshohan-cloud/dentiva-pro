## Known environment and product boundaries

- The local Linux sandbox could not perform a genuine Electron GUI run because Electron's binary download crossed the sandbox certificate boundary. No local GUI PASS is claimed; Windows CI supplied the portable release gate.
- Human Bangladeshi Bengali review of every dynamic, print and PDF surface remains recommended before broad commercial rollout.
- Domain/Node benchmarks do not claim packaged Electron startup, memory, search, report or backup/restore latency at 25,000 records.
- SQLite is local persistence, not encryption; use OS controls, full-disk encryption and protected backup media.
- A forgotten local PIN is not recoverable by Dentiva Pro; follow the clinic's verified recovery policy.

## Manual acceptance still required

**The Windows installed-app launch/restart/uninstall smoke was intentionally excluded from automated release gating and remains for manual user verification.**

The manual sequence is: install the published NSIS package, launch the installed application, create and retrieve a renderer storage profile, close it, relaunch it, verify the profile persists, uninstall it, and verify removal. This sequence must not be reported as an automated PASS.
