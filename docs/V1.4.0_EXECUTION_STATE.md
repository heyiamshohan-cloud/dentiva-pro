## Completed requirements (headline)

- Baseline recovered and verified: `npm test` → **46/46 pass** on v1.3.0 code at merge time.
- Environment verified: Node v22.22.3, npm 10.9.8; registry reachable; `node:sqlite`
  (SQLite 3.51.3) works locally without flags and is supported in Electron main process.
- Architecture decision recorded (see BASELINE_AUDIT §9): replace sql.js full-state store with
  relational `node:sqlite` schema v5 in the Electron main process; typed async IPC; renderer
  becomes a paginated client. Rationale: v1.3.0 rewrites the entire DB per save (O(N) sync IPC),
  caps store at 200 MB, caps attachments at 6 MB, keeps all records in renderer memory, and
  enforces RBAC only in the UI — all violate v1.4.0 mandates (§6–§10, §36, §62).
- `better-sqlite3` evaluated and rejected: prebuilt-binary download blocked in sandbox
  (TLS to objects.githubusercontent.com) and native rebuild blocked (nodejs.org headers
  unreachable); adds ABI/packaging risk on Windows CI. `node:sqlite` has zero packaging risk.
